# 🧪 DVWA

Damn Vulnerable Web Application (DVWA) is planned as the second intentionally vulnerable application in this lab repository.

---

## 🎯 Objective

Practice common web application vulnerabilities in a controlled local environment.

Planned areas include:

- SQL Injection
- XSS
- Command Injection
- File Upload
- CSRF
- Authentication
- Session Security

---

## 🚧 Status

🔜 Planned

Juice Shop is currently the primary application for this repository.

---

## ⚠️ Scope

DVWA testing will be performed only in my own local laboratory environment.

No external targets are included.
