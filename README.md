# 🧫 Vulnerable App Labs

Hands-on testing of intentionally vulnerable applications, run locally on my own machine. Each app has a findings log with steps, evidence, and fixes.

| App | Goal | Status |
|---|---|---|
| [OWASP Juice Shop](juice-shop/) | Find and document 5+ vulnerabilities | 🔨 In progress |
| [DVWA](dvwa/) | Practice classic vulns at all security levels | 🔨 Planned |

## Setup notes
Run apps in Docker on localhost only. Never expose them to the internet.

## Output
Findings from these labs feed into [pentest-report-samples](https://github.com/Gokulpvtr/pentest-report-samples).
